# 🎨 PackLab 3D — Brand Identity Design

## 🟦 1. Logo Concept (Main Logo + Alternatives)
The logo should reflect PackLab 3D’s triad of **science + design + production**.

### Main Concept: “Precision + Geometry + Lab”
- Minimal geometric lines  
- 3D cube or bottle silhouette  
- “PL3D” monogram inside  
- Thin lines evoking a laboratory feel  
- A rectangular/bottle form representing packaging  

### Logo Forms
**Main Logo:**  
3D wireframe cube → “PL3D” monogram inside  
Below: “PackLab 3D” text  

**Alternative Logo:**  
Bottle silhouette + label area  
Inside: “PackLab 3D” text  

**Minimal Logo:**  
Only “PL3D” monogram  
Used as small UI icon  

### Logo Typography
Sans-serif, sharp-edged, technical fonts:
- Inter  
- Manrope  
- Space Grotesk  
- Eurostile  
- Montserrat

## 🖥️ 3. UI Theme (Electron + Three.js)

### Main UI Style
- Flat modern  
- Minimal lines  
- Technical icons  
- Multi-language buttons (EN / TR / SW)

### UI Sections
- Left panel: measurement input form  
- Center panel: 3D viewer  
- Right panel: label design options  
- Bottom panel: export buttons  

### UI Animations
- 3D model loading → soft fade-in  
- Label placement → smooth slide  
- Language switch → instant UI refresh
