# i18n.md — PackLab 3D

## Languages Supported
- English (default)
- Turkish
- Swahili

## File Structure
/i18n/en.json  
/i18n/tr.json  
/i18n/sw.json  

## Requirements
- All UI text must be stored in language files.
- Backend messages must be localized.
- Label engine must support multilingual text.
- Language selector must switch UI instantly.
